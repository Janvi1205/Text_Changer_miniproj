📝 Overview
Text Styler is an elegant, browser-based text styling application that enables users to customize text with various visual effects and formatting options. Perfect for creating eye-catching text for social media, presentations, or creative projects.

✨ Features

Rich Text Formatting - Adjust font family, size, style (bold/italic), and color<br>
Live Preview - See changes in real-time as you modify settings<br>
Color Customization - Choose from an unlimited palette of text colors<br>
Font Control - Select from popular font families including Arial, Times New Roman, Georgia, and more<br>
Size Adjustment - Fine-tune text size with an intuitive slider<br>
Style Controls - Apply bold or italic formatting with a single click<br>
Copy to Clipboard - Instantly copy your styled text for use elsewhere<br>

🚀 Demo
Try out the live demo:https://janvi1205.github.io/Text_Styler_miniproj<br>


🛠️ Technologies Used
HTML5 - Structure and content<br>
CSS3 - Advanced styling with CSS variables and modern layout techniques<br>
JavaScript - Interactive elements and real-time styling application<br>
Local Storage API - Save user preferences between sessions<br>
Clipboard API - Enable copy functionality<br>
