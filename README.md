📝 Overview
Text Styler is an elegant, browser-based text styling application that enables users to customize text with various visual effects and formatting options. Perfect for creating eye-catching text for social media, presentations, or creative projects.

✨ Features

Rich Text Formatting - Adjust font family, size, style (bold/italic), and color
Live Preview - See changes in real-time as you modify settings
Color Customization - Choose from an unlimited palette of text colors
Font Control - Select from popular font families including Arial, Times New Roman, Georgia, and more
Size Adjustment - Fine-tune text size with an intuitive slider
Style Controls - Apply bold or italic formatting with a single click
Copy to Clipboard - Instantly copy your styled text for use elsewhere

🚀 Demo
Try out the live demo:https://janvi1205.github.io/Text_Changer_miniproj


🛠️ Technologies Used
HTML5 - Structure and content
CSS3 - Advanced styling with CSS variables and modern layout techniques
JavaScript - Interactive elements and real-time styling application
Local Storage API - Save user preferences between sessions
Clipboard API - Enable copy functionality
